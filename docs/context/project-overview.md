# Project Overview — Scavvy

## What Scavvy Is

Scavvy is an Expo/React Native mobile app that turns the user's real surroundings into short AI-generated scavenger/adventure quests.

The product's differentiator is not simply "AI generates a scavenger hunt."

The differentiator is:

**Scavvy visually scans the user's environment first, remembers what is there, then creates missions and hints grounded in that environment.**

## Core Product Promise

**Your world is the game.**

The user should feel accompanied by Scavvy, a curious raccoon explorer, rather than feel like they are using an AI utility.

## Core Loop

1. Start Adventure
2. Select location type
3. Scan environment with 3 photos
4. AI understands the space
5. AI creates 3 contextual sidequests
6. User chooses a quest
7. User searches using the camera
8. User submits a verification photo
9. AI validates
10. Scavvy reacts
11. Voice plays
12. XP is awarded
13. Repeat
14. Complete adventure

"What can I unlock next?"

## MVP Strategy

This is a hackathon-first build.

Optimize for:

- one magical live demo
- reliable camera flow
- real environment awareness
- fast feedback
- strong mascot identity
- working audio fallback
- polished native-feeling mobile UI

Prefer a small complete flow over broad incomplete scope.

## Non-Goals

No real AR/SLAM, multiplayer, payments, subscriptions, social feed, or admin system for MVP.

# Scavvy

**Your world is the game.**

Expo / React Native adventure app. Scan a space, get quests, play. Runs fully on the frontend — no backend needed.

```bash
cd frontend
npm install
npx expo start
```

Press `w` for web, or scan the QR with Expo Go.

See [frontend/README.md](frontend/README.md) and [docs/required.md](docs/required.md).
